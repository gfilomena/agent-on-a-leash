# Agent on a Leash (Viseca case)

Wallet control layer for AI shopping agents. Hackathon project for Viseca's challenge at Swiss {ai} Weeks 2026.

- `PRODUCT.md`: what we build
- `CLAUDE.md`: brief for Claude Code (read automatically)
- `docs/CASE_NOTES.md`: lessons, traps, calibration notes
- `viseca-2026-main/`: Viseca's case materials and data pack

## Setup

1. Copy `.env.example` to `.env` (already done locally) and paste the keys.
2. Start Claude Code in this folder and ask it to read `CLAUDE.md` and `PRODUCT.md` and propose a plan.
